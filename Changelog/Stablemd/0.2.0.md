## FFX Compatibility Tool v0.2.0

FFX Compatibility Tool 0.2.0 brings every After Effects from CS5.5 through 2025, a Windows-theme follower, verbose bug-report logging, and a real update check — all in one portable exe.

## ✨ What's New

- All fifteen After Effects targets — CS6 and every Creative Cloud release from 2013 through 2025 join CS5.5 in the picker. CS5.5 keeps its byte-verified full downgrade; newer versions get native-format strip mode, so no version bytes are invented or guessed.
- "Follow the Windows theme" switch in Settings → Appearance — the app flips between light and dark the moment Windows does.
- Verbose Logging in Settings → Storage — every conversion step with timings lands in %LOCALAPPDATA%\FFXCompatibilityTool\logging.json, ready to attach to a bug report.
- A real Check for Updates — the About page button compares your build against the newest GitHub release and opens that release's exact page.
- A README that shows the app — five real screenshots (Convert, batch runs, Effect Lister, Settings) and the fifteen-target table.
- winget on its way — `winget install Marbou92.FFXCompatibilityTool` is in review, and future releases offer themselves to the catalog automatically.
