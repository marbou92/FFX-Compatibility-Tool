## FFX Compatibility Tool v0.2.2

FFX Compatibility Tool 0.2.2 finishes the settings-page rebuild — five panels on one shared row system with a search that jumps, every checkbox replaced by a real switch, an Updates panel in the classic update-settings shape with a changelog you can browse release by release, and a Plugin Profiles grid that filters, bulk-links and catalogs what your scan finds.

## ✨ What's New

- A settings search that jumps — type in the box at the top of Settings and pick a match: the app switches to the right panel and flashes the row you asked for. Twenty-four rows are indexed across all five panels, so "logs", "palette", "nightly" or "version" all land somewhere useful.
- One shared row system — every setting sits in the same rounded row (icon tile, title, caption, control on the right) with a hover state, grouped under small uppercase headers inside each card, across five panels: Appearance, Storage, Plugin Profiles, Updates and About.
- The theme controls grow up — the dark-mode switch and the follow-the-Windows-theme checkbox become one three-way Light / Dark / System segmented control, the chosen palette swatch wears a checkmark chip that pops in with a small spring, a live preview card re-renders as you pick, and Restore Defaults is a real two-step button that tells you what it did instead of a silent surprise.
- Storage tells the truth at a glance — a stacked meter shows what the plugin scan catalog, the recent-presets history and the session logs actually occupy; deletes confirm in place (the button turns into a red "Confirm delete?" for three seconds — no popup) and settle with a toast, and opening the storage folder or the logs is a row like everything else.
- The checkmark era ends — every boolean in Settings carries a real switch now (the rounded pill with the white knob: verbose logging, the automatic check, nightlies, notifications) and the whole row toggles with it, while the marks that aren't controls follow what they mean: the profile card badges read as mini-pills (a tiny primary pill with the dot parked right, a ghost pill with the dot left when off) and the selected palette swatch wears a checkmark chip — a pick is a chosen state, not a toggle.
- Updates becomes its own panel — the classic update-settings shape: a System update row whose value says Up to date, Checking…, or the new version and unfurls See what's new, Release page and Skip this version when something's out (clicking the row runs the check, or opens the updater when a release is waiting), an App version row that copies on click and says when this exe was built, a Flavour row that says Stable or Nightly, and a Clear downloaded updates row that reports — and deletes — whatever a previous download left staged.
- Nightlies become opt-in — Include nightlies checks the rolling prerelease builds too, compared by publish date instead of a version number (a nightly's number never moves), so a nightly hit opens its release page instead of pretending to install; a Notify switch gates the corner toast while the tab's dot shows either way; and a version you skip stays quiet until the next release.
- A changelog you can browse — the Changelog row drills into a strip of version pills fetched straight from GitHub: pick v0.2.2, v0.2.1 or v0.2.0 and that release's date, hero image, description and full notes render below, parsed with the same rules the release workflow uses.
- About keeps links and details only — the identity row wears a STABLE or NIGHTLY channel chip and copies on click, the paragraph wall becomes one line plus specs chips (Windows 10+, .NET Framework 4.8, single exe, no installer), and a Copy SHA-256 row hands you the exact hash the release page publishes.
- Plugin Profiles get productive — a filter box narrows both sections as you type, Link all and Unlink all sit on the section headers behind a two-step confirm, a scan reports one chip per recognized vendor ("Trapcode — 12 files") and offers the detected AE Plug-ins folder as a one-click link, Add custom vendor actually adds vendors now (future scans match the name against plugin paths), each card shows how many .aex files the catalog holds for it, and cards fade into place as they move between sections.
- Everything remembers where you were — Settings reopens on the last of the five tabs you visited and Alt+1…5 switches them from the keyboard.
